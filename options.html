Lore settings

LLM provider (BYOK)

Your key is stored locally in this browser profile and sent only to the provider you pick. Questions and the context slices needed to answer them are sent to that provider on each draft.

Discover programs

Lore re-checks accelerator and VC apply pages on a schedule (in your browser — no server) and flags newly opened applications with a NEW badge. Add any program page you want watched.

Applications

Every program you've applied to (or plan to). The side panel's Save to history adds entries here automatically. Notes are private — never sent to the LLM.

Founder context

This is the product: one portable file of verified facts about your company. Fields with a ✓ verified toggle are facts the extension checks every draft against — numbers the model may never alter. List fields take one item per line.

Pitch deck: the PDF is sent once to your selected provider/model, which proposes values for empty fields. Everything it extracts is marked unverified — review each field before relying on it.
